# ScalerChat — Persona-Based AI Chatbot

## Overview
A persona-based chatbot where users can talk to:
- Anshuman Singh
- Abhimanyu Saxena
- Kshitij Mishra

Each persona has unique tone, beliefs, and communication style.

---

## Features
- Persona switching (resets chat)
- Suggestion chips
- Typing indicator
- Responsive UI
- Gemini-powered backend

---

## Project Structure
frontend/ → UI  
backend/ → API  

---

## Setup

### Backend
cd backend  
npm install  
cp .env.example .env  
(add your GEMINI_API_KEY)  
node server.js  

### Frontend
cd frontend  
open index.html  

---

## API Endpoint
POST /api/chat
